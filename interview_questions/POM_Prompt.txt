3. Page Object Model Design

Implement proper POM classes where:

- each page has its own class file

- locators are private or well-encapsulated

- methods represent user actions and validations

- no raw locators inside test files

- reusable page methods are created for common actions

- LoginPage

- HomePage

- SearchPage or DashboardPage

Use meaningful methods like:

- verifyHomePageLoaded()
